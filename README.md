# Stack Overflow Developer Survey Analysis

## 📌 Project Overview

This project analyzes data from the **Stack Overflow Developer Survey** to identify patterns in developer experience, programming language usage, remote work, learning methods, education, and compensation.

The analysis was performed using **Python in Google Colab**.

## 🎯 Project Objectives

The analysis focuses on:

* developer professional experience;
* remote work adoption;
* Python usage;
* online learning and courses;
* Python developer compensation across countries;
* education levels among the highest-paid respondents;
* Python usage across age groups;
* industries represented among highly paid remote workers.

## 🛠️ Tools & Technologies

* Python
* Pandas
* NumPy
* Matplotlib
* Google Colab
* GitHub

## 🔍 Data Preparation

The dataset was prepared for analysis using Python and Pandas.

Main data preparation steps included:

* removing duplicate respondents using `ResponseId`;
* handling missing values;
* converting compensation values to numeric format;
* filtering data for specific analytical tasks;
* creating derived variables for Python usage and other indicators.

After removing duplicate `ResponseId` values, the dataset contained **49,181 unique respondents**.

## 📊 Analysis

The project contains 10 analytical tasks covering:

1. Total number of respondents.
2. Completeness of survey responses.
3. Developer professional experience.
4. Remote work adoption.
5. Python usage among respondents.
6. Online learning and courses.
7. Compensation of Python developers by country.
8. Education levels of the highest-paid respondents.
9. Python usage by age group.
10. Industries represented among highly paid remote workers.

## 📈 Visualizations

Several visualizations were created in Python to communicate the main patterns identified during the analysis.

The visualizations focus on programming language usage, developer characteristics, compensation, and work arrangements.

## 🔑 Key Findings

* The cleaned dataset contains **49,181 unique respondents**.
* Average professional experience was **13.37 years**, with a median of **10 years**.
* **37.5%** of respondents reported using Python.
* Python usage was highest among respondents aged **18–24 (63.27%)**.
* Python usage generally decreased across older age groups, reaching **45.15%** among respondents aged 65+.
* Compensation varied considerably across countries among Python developers.
* The highest reported compensation values included respondents with Associate, Master's, and Bachelor's degrees.
* **Software Development** was the most represented industry among the analyzed highly paid remote workers, with **316 respondents**.
